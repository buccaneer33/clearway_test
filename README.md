# CLEARWAY TEST

Проект основа на [Angular CLI](https://github.com/angular/angular-cli) version 20.1.5.

## Development server

Что бы запустить проект наберите в консоли:

```bash
ng start
```

Веб-сервер разработчика запускается на `http://localhost:4200/`. А дальше редиректы роутера вынесут вас автоматом.

Что реализовано: 
- standalone конфигурация для работы с моками. Легко и быстро можно переключиться для работы с бэком заменив конфигурацию.
- система роутинга автоматом отправляет по нужному маршруту.
- система увеличения документа включая работу зума из контекстного меню.
- реализованы аннотации с помощью Abgular SDK. Их можно создавать, перемещать, удалять. Аннотации сохраняются в localStorage.

Известные проблемы:
- перемещение по странице с помощью скролла не приводит к обновлению параметра в адресной строке. Рефреш страниы отправляет обратно на ту чать где вы были.
- увеличение страницы меняет точки рендера контекстного меню.
